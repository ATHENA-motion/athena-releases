# ATHENA app downloads

This repository hosts versioned ATHENA companion app installers. Application source is maintained separately in a private repository.

**The first qualified release candidate is not yet available.** No installers have been published here yet.

- [User guide](https://athena-motion.github.io/athena-docs/guide/)
- [Download and installation instructions](https://athena-motion.github.io/athena-docs/guide/downloads/)
- [Published releases](https://github.com/ATHENA-motion/athena-releases/releases)

Releases target Apple Silicon Macs, Intel Macs, and Windows x64. Initial release candidates will be unsigned and will include SHA-256 checksums, a release catalog, and the exact user guide bundled in the app. Follow the download page for supported operating systems and installation instructions for each published version.

These pages are publicly accessible but are not promoted for search indexing. Public GitHub repository contents and releases can still be discovered.
